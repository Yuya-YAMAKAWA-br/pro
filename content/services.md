## SERVICE 01｜総合マーケティング伴走

### タイトル
```
総合マーケティング伴走
```

### キャッチコピー
```
「何から手をつければいい？」を、一緒に解決します。
```

### 本文（サービスページ掲載用）
```
マーケティングの課題は、広告・SEO・SNS・UI改善など多岐にわたります。
しかし、それぞれを別々に対応していては、全体最適は生まれません。

BRAIDEAは、戦略設計から施策実行・効果測定まで、
貴社のマーケティングチームとして一体で動きます。
「外注先」ではなく「仲間」として、成果が出るまで伴走します。
```

### こんな企業に向いています
```
・社内にマーケティング専任担当がいない
・施策がバラバラで、全体の方向性が見えない
・代理店任せになっていて、改善が進まない
・新規事業・事業転換のタイミングで戦略を作り直したい
```

### 支援内容
```
・マーケティング戦略立案・KPI設計
・チャネル横断の施策ロードマップ作成
・月次レポート・改善提案
・定例ミーティングによるPDCA運用
・各施策（広告・SEO・LP等）の実行支援
```

### 料金感（参考）
```
月額 ¥150,000〜（内容・規模により応相談）
```

## SERVICE 02｜デジタル集客

### タイトル
```
デジタル集客
運用型広告 / リスティング広告 / SNS広告
```

### キャッチコピー
```
広告費を「かけている」から「効かせている」へ。
```

### 本文
```
「広告費は使っているのに、成果が見えない」——
その原因は、運用の質にあることがほとんどです。

BRAIDEAは、Google・Meta・LINEなどの主要媒体を横断的に管理し、
ターゲット・クリエイティブ・入札戦略を一体で最適化。
ROASの最大化と、無駄な広告費の削減を同時に実現します。
```

### こんな企業に向いています
```
・リスティング広告やSNS広告を始めたいが、やり方がわからない
・代理店に任せているが、レポートの内容が理解できない
・広告費を増やしたいが、効果に自信が持てない
・BtoBリードを広告で獲得したい
```

### 支援内容
```
・Google広告（検索・ディスプレイ・P-MAX・YouTube）
・Meta広告（Facebook / Instagram）
・LINE広告 / X(Twitter)広告
・クリエイティブ（バナー・動画）制作・A/Bテスト
・ROAS改善・予算配分最適化
・月次レポート・改善提案
```

### 料金感
```
初期費用 ¥50,000〜 ＋ 月額運用費（広告費の15〜20%、または固定費）
※ 広告費は別途
```

## SERVICE 03｜サイト改善（LLMO/SEO・コンテンツマーケティング）

### タイトル
```
サイト改善
LLMO / SEO / コンテンツマーケティング
```

### キャッチコピー
```
Google検索だけじゃない。AI検索にも選ばれるサイトへ。
```

### 本文
```
ChatGPT・Perplexity・Geminiなど、
ユーザーが「検索」ではなく「AI」に質問する時代が来ています。

従来のSEOに加え、LLM（大規模言語モデル）に
自社の情報を正確に引用・推薦してもらうための
「LLMO（LLM Optimization）」対策が、今後の集客の鍵を握ります。

BRAIDEAは、テクニカルSEOからコンテンツ戦略まで、
次世代の検索最適化を包括的に支援します。
```

### こんな企業に向いています
```
・サイトのアクセスが伸び悩んでいる
・以前SEO対策をしていたが、効果が落ちてきた
・AI検索時代に対応したコンテンツ戦略を作りたい
・自社のノウハウをコンテンツ化して集客したい
```

### 支援内容
```
・LLMO対策（AI検索エンジン最適化）
・テクニカルSEO監査・改善（サイト速度・構造化データ等）
・キーワード戦略設計・競合分析
・コンテンツ戦略設計・記事制作
・内部リンク・サイト構造最適化
・Search Console / GA4 を活用した効果測定
```

### 料金感
```
月額 ¥100,000〜（コンテンツ制作本数・規模により変動）
```

## SERVICE 04｜LPO / UI・UXデザイン / アクセス解析 / 生成AI導入支援

### タイトル
```
LPO / UI・UXデザイン / アクセス解析 / 生成AI導入支援
```

### キャッチコピー
```
集客の「その先」を、データで最適化する。
```

### 本文（LPO・UX）
```
広告やSEOで集客できても、サイトやLPで離脱されては意味がありません。
BRAIDEAは、ヒートマップ・行動分析・A/Bテストを活用し、
ユーザーが「問い合わせ・購入・申込」まで自然に進める
導線とUIを設計します。
```

### 本文（生成AI導入）
```
「AIを使いたいが、何から始めればいいかわからない」
そんな企業のために、業務に合った生成AI活用を設計します。

マーケティング業務の効率化（コンテンツ生成・レポート作成）から、
社内ナレッジ活用・カスタマーサポートの自動化まで、
実際に運用できる形で導入を支援します。
```

### こんな企業に向いています
```
・LPやサイトの問い合わせ率・CVRを上げたい
・どこでユーザーが離脱しているか把握できていない
・GA4に移行したが、使いこなせていない
・生成AIの社内活用を進めたいが、方法がわからない
・ChatGPT等を導入したが、業務に定着していない
```

### 支援内容
```
【LPO / UI・UX】
・LP改善提案・A/Bテスト設計・実施
・UI/UXデザインレビュー・改善提案
・ヒートマップ分析（Hotjar / Microsoft Clarity等）
・フォーム最適化・CTA改善

【アクセス解析】
・GA4 設定・カスタム計測
・コンバージョン計測・ファネル分析
・月次レポート作成・改善提案

【生成AI導入支援】
・AI活用ロードマップ設計
・ChatGPT / Claude / Gemini の業務活用設計
・プロンプト設計・運用ルール策定
・社内研修・ワークショップ実施
```

### 料金感
```
スポット対応：¥80,000〜
月次支援：¥80,000〜/月
AI導入支援：¥200,000〜（プロジェクト規模による）
```

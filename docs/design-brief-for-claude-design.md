# Claude Design 用デザインブリーフ（コピペ用）

以下をそのまま Claude Design（claude.ai/design）に貼り付けて使用してください。

---

【依頼】BtoBマーケティング支援会社のコーポレートサイト「トップページ」をデザインしてください。

## 会社概要
- 社名: 株式会社ブレイディア（BRAIDEA）
- 事業: BtoBデジタルマーケティング支援・採用支援（コンサルティング + 実行伴走）
- ターゲット: 中小〜中堅企業の経営者・マーケティング責任者
- 強み: 戦略〜実行〜内製化まで一気通貫。LLMO・生成AI活用に強い

## トーン & マナー
- 信頼感・専門性・先進性（「AI時代のパートナー」という立ち位置）
- 過度にポップにしない。BtoBらしい品格を保ちつつ、堅すぎない
- 参考イメージ: LANY（lany.co.jp）のような清潔感のあるBtoBコンサルサイト
- 現行案は濃紺(#1a1a2e) × オレンジ(#f97316)のカラー。刷新も歓迎だが、
  CTAボタンが目立つ「暖色アクセント」はCVR観点で効果的だったので考慮してほしい

## ページ構成（コピーは確定済み。文言はこのまま使用）

1. **ヘッダー**
   - ロゴ: BRAIDEA
   - ナビ: サービス / 支援事例 / ご支援の流れ / 資料ダウンロード / 会社情報 / お問い合わせ(CTAボタン)

2. **ヒーロー**（フルスクリーン・背景動画あり・暗めオーバーレイ + 白文字）
   - 英字ラベル: INTEGRATED MARKETING PARTNER
   - 見出し: AI時代に、選ばれ続ける企業をつくる。
   - サブコピー: 戦略立案から広告運用・サイト改善・AI導入まで。成果にコミットする、伴走型マーケティング支援。
   - ボタン2つ: 「無料相談はこちら」「資料ダウンロード」

3. **課題提起**（3カード）
   - 広告費をかけているが成果が見えない
   - SEO対策が追いつかない
   - 生成AIを活用したいが何から始めるべきか

4. **サービス**（4カード・各カードにタグと「詳しく見る」ボタン右下配置）
   - 総合マーケティング伴走
   - デジタル集客
   - サイト改善（LLMO/SEO）
   - LPO / UI・UX / 解析 / AI導入

5. **お役立ち資料**（ホワイトペーパー4点の紹介 + 「資料一覧を見る」ボタン）

6. **ご支援の流れ**（4ステップ横並び）
   - 無料相談 → 戦略提案 → 施策実行 → 効果測定・改善

7. **お問い合わせCTA**（濃色背景・センター配置）
   - まずは無料でご相談ください

8. **フッター**

## 要件
- 日本語サイト
- レスポンシブ対応（PC・スマートフォン両方のデザインが見たい）
- ヒーローは背景動画前提（動画の上に暗めのオーバーレイ + 白文字）
- 実績数値セクションは入れない（実績が揃うまで意図的に非公開のため）
- HTML/CSSで実装しやすい構造にしてほしい

---

## 生成後にやること

1. 気に入ったデザインができたら、**生成されたHTML/CSSコード**をコピー
2. Claude Code のセッションに貼り付けて「このデザインを反映して」と依頼
3. Claude Code 側で全16ページへの展開・GitHub反映・Xserver用の整理を実施
